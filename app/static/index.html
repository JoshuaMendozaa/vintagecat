VISION

Local Ollama

Your photos are sent to your configured Ollama server. Model quality needs testing on your garments.

Install Ollama and pull the model in README.md. Set a smaller model in config.local.toml for the Mac if needed, then restart.

SOLD CANDIDATES

CompsAPI · optional

Third-party results remain provider-reported until reviewed. Only your search text is sent; garment photos stay with the vision provider.

Set COMPSAPI_KEY in your environment or config.local.toml. No key is stored in the browser. No automatic subscription or purchase.

SCOPE

Research before publishing

This version saves and researches garments. It does not publish, connect seller accounts, authenticate garments, or sync sales.

Manual comps work without any API key. Your catalogue works without Ollama. Back up the entire data folder for photos and records.
